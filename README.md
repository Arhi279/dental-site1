# Дентал Студіо

Статичний багатосторінковий дизайн-концепт. Клініка не здійснює прийом пацієнтів.

## Перегляд
Відкрийте index.html у браузері або розмістіть корінь репозиторію на GitHub Pages / Cloudflare Pages. Збирання та залежності не потрібні. Усі внутрішні посилання відносні й сумісні з підкаталогом GitHub Pages.

## Сторінки
- index.html — компактна головна
- services.html — каталог
- caries.html, hygiene.html, whitening.html, orthodontics.html — деталі процедур
- doctors.html, doctor-profile.html — демонстраційні профілі
- reviews.html — стан без реальних відгуків і шаблон
- prices.html — прайс із полями для підтверджених цін
- about.html — підхід, етапи візиту та галерея
- faq.html — усі запитання та навігація
- contacts.html — контакти, графік, місце для карти та Formspree

## Редагування для клієнта
Редагуйте текст безпосередньо у відповідному HTML. Спільні стилі — styles.css, меню й перевірка форми — script.js. Шапка та футер присутні в кожному HTML: під час зміни меню оновлюйте всі сторінки.
У doctors.html і doctor-profile.html замініть поля лише підтвердженими даними та погодженими фотографіями. У reviews.html замініть демонстраційний макет реальними текстами, датами, іменами за згодою й посиланнями на першоджерело; не додавайте вигаданих оцінок.
У prices.html скопіюйте блок price-row для нової позиції, заповніть ціну та склад послуги. Нові напрями публікуйте лише після підтвердження клієнтом.
У about.html замініть photo-placeholder на img з локальним шляхом, alt, width і height. У contacts.html заповніть контакти та графік; підключайте карту лише для підтвердженої адреси. Не підставляйте випадкові адреси.
Formspree перенесено без зміни endpoint, полів, згоди та логіки надсилання. Перед запуском для реальної клініки погодьте обробку персональних даних і замініть тестові попередження відповідними реальними повідомленнями. До цього не надсилайте справжні персональні дані.

## 3D-анатомія зуба

`tooth-anatomy.html` — окрема освітня сторінка. На головній є лише компактне посилання; 3D-бібліотека там не завантажується. Для локального перегляду ES-модулів запустіть HTTP-сервер із кореня репозиторію, наприклад `python -m http.server 8000`, і відкрийте `http://localhost:8000/tooth-anatomy.html` (модулі не працюють через `file://`).

- **Модель:** оригінальна процедурна геометрія в `tooth-model.js`, створена для цього проєкту; не завантажена з фотобанку, не скан пацієнта. Спрощений однокореневий різець: емаль коронки, дентин, пульпова камера й канал, тонкий шар цементу на корені. Видалений передній квадрант показує внутрішні тканини; можна перемикатися на цілий зуб. Кольори та пропорції умовні, ясна й кістка не показані. Це освітня ілюстрація, не засіб діагностики.
- **Рендерер:** Three.js 0.180.0 + OrbitControls, MIT. Локальна оптимізована збірка та повний текст ліцензії — `assets/vendor/`. Походження й команда відтворення збірки — `assets/vendor/README.md`.
- **Керування:** миша/один палець — обертання, колесо/два пальці — масштаб; кнопки масштабу й скидання; клавіші стрілок, +/− і Home на сфокусованому canvas. Пояснення доступні також окремими кнопками та текстом без 3D.
- **Відмовостійкість:** початковий індикатор, обробка помилки імпорту/WebGL/втрати контексту, локальна резервна SVG-схема (`assets/tooth-fallback.svg`, оригінальна ілюстрація цього проєкту). Без JavaScript залишається схема й текстова версія.
- **Продуктивність:** близько 20 тис. трикутників для двох варіантів разом, DPR обмежено 1.5; малювання лише під час взаємодії/зміни розміру, пауза поза екраном і в прихованій вкладці; reduced motion вимикає інерцію та анімацію скидання.

Розширення: можна додати інші типи зубів, більше навчальних позначок або погоджену стоматологом деталізовану GLB-модель із документованою ліцензією. Усі зміни моделі слід перевіряти на анатомічну коректність; не додавати діагностичних висновків.
