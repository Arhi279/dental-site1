# 🦷 Пошук клієнтів (Dental Lead Finder)

Окрема вебпрограма українською для пошуку публічних бізнес-контактів стоматологій. **Основний сайт у корені репозиторію не змінюється.**

## Через браузер / Codex
1. Відкрий цей репозиторій у Codex та скажи: «Запусти застосунок із lead-finder/app.py. Встанови залежності з lead-finder/requirements.txt і покажи вебперегляд».
2. Якщо потрібне окреме постійне посилання: відкрий https://share.streamlit.io/, підключи цей GitHub-репозиторій, обери шлях до додатка **lead-finder/app.py** і натисни Deploy.
3. У програмі обери міста та натисни «Знайти контакти».
4. Перевір бізнес-сторінку та місто, після чого можеш написати в Direct / email без дзвінків.
5. Експортуй CSV після редагування статусів — зміни у браузері можуть загубитися.

## Локально (Python 3.10+)
```bash
python -m pip install -r lead-finder/requirements.txt
python -m streamlit run lead-finder/app.py
```

## Важливо
- Інформація береться з публічної бази OpenStreetMap та стороннього вебпошуку (DDGS); джерела можуть повертати неповні або неточні дані.
- **Відсутність сайту у відкритому каталозі — не доказ, що сайту немає.** Перевір особисто.
- Instagram-профіль з результатів пошуку може бути не з того міста — звіряй дані.
- Програма не надсилає автоматичних повідомлень, не збирає приватних даних і не гарантує продажів.
- Для OSM застосовуються умови ODbL. Для Nominatim дотримуйся політики обмеження запитів.
- Вебпошук може тимчасово не спрацювати через ліміти сервісу.
