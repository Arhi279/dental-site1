## Processing and delivery

The downloaded copies may already be cropped and color graded; the dental set’s source register documents a cooled, reduced-saturation treatment. Local processing resized the images, preserved their aspect ratios, and encoded WebP responsive variants. The two portraits use 800 × 1000 px derivatives and 480 px-wide alternatives. Larger landscape files are capped at 1200 px; smaller originals are not enlarged.

The HTML supplies intrinsic dimensions, responsive `srcset`/`sizes`, descriptive Ukrainian `alt` text, `object-fit: cover` where appropriate and lazy loading below the first screen. All image bytes are served locally. Sources and licenses remain documented here rather than creating repeated technical captions in the page design.
